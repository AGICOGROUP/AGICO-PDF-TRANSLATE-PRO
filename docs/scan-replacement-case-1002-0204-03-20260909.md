### 4. 覆盖排版

- 使用 OCR 字形包围框作为 `clean_box` 或 `clean_boxes`，只清除原文字形。
- 跨行注释使用多个紧密清除框，避免擦除表格线、尺寸线、引线和签名。
- 译文目标框使用对应文字区域的并集，仅增加少量边距。
- 译文保持源文字方向；本页绝大多数块为 90°。
- 标题、正文、批注和表格文字分别使用统一基础字号。
- 只有内容确实放不下时才允许该完整段落缩小，禁止单独缩小其中几个字。
- 中文使用微软雅黑字体；标题加粗，其余按原图层级处理。

## 本次效率结论

这份文件采用的有效提速点是：

1. 根据源图真实分辨率选择 300 DPI，避免无收益的 400 DPI 重采样。
2. 单次 OCR 已能识别主要文字，因此不运行双尺度 OCR。
3. 一次生成完整翻译清单，跨行文字在翻译阶段直接合并。
4. 一次构建、一次整页渲染、一次集中质检，未触发修复循环。
5. 尺寸和标识符直接保留，不对无须翻译的内容重复处理。

已记录的核心程序阶段用时为 OCR 13.796 秒、PDF 构建 1.544 秒。人工语义复核、清单整理和视觉检查未单独计时，因此不能把上述两项之和当作完整端到端用时。

## 复用原则

- 先路由，再选择适配器。
- OCR 分辨率以源图有效像素为依据，不固定追求更高 DPI。
- 只有首轮 OCR 明显遗漏或低置信度时才重跑局部或双尺度 OCR。
- 翻译按整页上下文进行；放置仍按源文字 ID 精确追踪。
- 清除范围只覆盖字形，任何结构线都视为受保护内容。
- 只在实际发现阻塞问题时返工，不为增加门禁而增加门禁。
