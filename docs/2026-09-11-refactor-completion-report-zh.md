## 分阶段落地

1. **可信基线与直接缺陷**：统一 pytest 入口；原生/CAD 任务绑定目标语言；fresh 创建独立任务；已完整双语直通核对实际请求语言组合；CAD 在擦除源文字前检查可见页面边界，包括旋转、裁剪页面。详见 [第一阶段记录](2026-09-11-refactor-phase1-results.md)。
2. **CAD 语义单元**：prepare 导出带整页原文上下文的 `translation-units.json`；保守聚合同一行的原生碎片，不跨单元格、保护尺寸、方向和结构边界。`merge-units` 将一份完整译文导入原有 leader/merged 契约，保留所有源 ID；源、请求、库存和成员冲突时不部分覆盖。多行条款和人工库存修正继续走已有 packet，不强行自动成段。
3. **局部重算**：CAD 复核按页面内容、局部记录及工件哈希复用，损坏或改动页重建；扫描缓存实际单页 PDF 与测量报告，按选定顺序组装，字体/源像素/实现/布局变化使其失效。缓存不生成语义或视觉通过证据，最终 QA 仍绑定完整候选。保留 `--no-page-cache` 完整绘制路径。
4. **OCR 与计时**：OCR 缓存绑定默认模型、配置、依赖和页面身份；缓存命中不构造引擎，保留瓦片与全页补充识别；修正旋转 OCR 和复核裁剪坐标。新增可选 `session_metrics.py`，记录实际主动墙钟时间、失败重试和显式暂停；它不控制 QA、不能补记首次 start 之前的耗时，也不是新门禁。没有无证据地增加 OCR 并发。
